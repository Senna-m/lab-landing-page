# Clinical Laboratory Landing Page

A simple front-end landing page developed for a clinical laboratory website.
The goal of this project is to practice HTML, CSS and layout structuring, creating a clean and informative page for laboratory services.

This project simulates an institutional website where patients can access information about services, contact details, and exam results.
